# Sổ Xe Android

Ứng dụng Android quản lý chi phí xe ô tô, dùng chung dữ liệu Google Drive với bản web.

APK mở ứng dụng tại:
https://quan-ly-chi-phi-xe.fluffy-hill-7538.chatgpt.site

## Tạo APK

Workflow **Build So Xe APK** tự động tạo file `So-Xe-Android.apk` đã ký để cài trực tiếp trên Android. Ứng dụng dùng Trusted Web Activity/Chrome để luồng đăng nhập Google Drive tuân thủ chính sách OAuth của Google.
