SỔ XE WINDOWS PORTABLE 1.1.9
================================

KHÔNG CẦN CÀI ĐẶT

1. Giải nén toàn bộ file ZIP vào một thư mục.
2. Bấm đúp file Chay-So-Xe.bat.
3. Ứng dụng mở bằng trình duyệt mặc định của Windows.
4. Nếu trình duyệt đã đăng nhập Google, màn hình kết nối Drive sẽ cho chọn
   ngay tài khoản Google đã lưu.

LƯU Ý

- Không chạy trực tiếp file BAT khi file ZIP chưa được giải nén.
- Không xóa riêng thư mục www nằm cạnh file BAT.
- Ứng dụng dùng được khi mất mạng. Khi có mạng, dữ liệu chờ sẽ tự đồng bộ Google Drive.
- Trước khi đổi từ bản 1.1.4, hãy bảo đảm dữ liệu đã đồng bộ Google Drive.
- Dữ liệu cục bộ được giữ tại: %APPDATA%\SoXeData
- Nếu không mở được, kiểm tra 2 file:
  %APPDATA%\SoXeData\SoXeBat.log
  %APPDATA%\SoXeData\SoXeLauncher.log
- Khi cập nhật, chỉ cần tải ZIP mới, giải nén và chạy; dữ liệu cũ không bị xóa.
- Để Google Drive hoạt động, Authorized JavaScript origins của OAuth Web cần có:
  http://127.0.0.1:18765

Nếu Windows chặn file BAT, bấm chuột phải vào file ZIP trước khi giải nén,
chọn Properties (Thuộc tính) -> Unblock (Bỏ chặn) -> Apply.

Neu ban cu van dang chay, dong SoXeLauncher.exe cu trong Task Manager, roi chay lai Chay-So-Xe.bat ban 1.1.9.
